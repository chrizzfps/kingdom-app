# Guía de uso del panel de edición

## Principios generales
1. Prioriza títulos claros y breves (3–120 caracteres).
2. Mantén subtítulos entre 60–160 caracteres para legibilidad.
3. Usa párrafos cortos y listas para mejorar el escaneo.
4. Respeta validaciones: campos obligatorios, longitudes y formatos.
5. Verifica siempre el modo oscuro y claro.

## Hero
- Title: obligatorio, claro y directo.
- Subtitle: complementa el título; evita redundancias.
- Fondo: imagen legible o degradado; evita texto sobre áreas con bajo contraste.
- Overlay: utiliza valores 10–60 para mejorar legibilidad de textos.
- Alineación: izquierda, centro o derecha según composición.
- Animación: sutil en la entrada; no bloquear interacción.

## Intro
- Heading: breve y con intención (3–120).
- Content: párrafos cortos; evita bloques extensos.
- Solution Summary: 1–2 frases; puede ser en estilo cita.

## Options
- Title y Description: concisos y orientados a valor.
- Details: permite HTML simple para bullets o énfasis.
- Badge: usa “Popular” o “Rápido” para diferenciar.
- Toggles: marca `popular` o `fast` cuando aplique.

## Pricing
- Concept: obligatorio; describe el servicio o línea.
- Category: opcional; se usa para el desglose por segmento.
- Price: número; evita valores negativos.
- Discount: entre 0–100%; aplica cálculo automático y muestra precio tachado.
- Badge: “Oferta”, “Descuento”, “Popular” o “Rápido” como presets cortos.
- Highlight/Popular: resalta líneas clave y añade diferenciación visual.

## Timeline
- Phase: breve y distinguible (por ejemplo, “Week 1”).
- Task: describe la actividad concreta.
- Important: marca hitos clave; se muestra con pulso visual.
- Badge: etiqueta corta para destacar (“Milestone”, “Entrega”).
- Progreso: la línea crece conforme el paso activo entra en viewport.

## Payment
- Terms: redacta en frases claras; usa saltos de línea para secciones.
- Visual: capa decorativa sutil, sin bloquear lectura.

## CTA
- WhatsApp: formato `+123456789` (6–15 dígitos).
- Email: formato estándar con dominio válido.
- Botones: grandes y con texto claro; revisa que los enlaces funcionen.

## References
- Título/Categoría: descriptivos y concisos.
- Descripción: breve; evitar párrafos largos.
- Enlace: URL válida; evita duplicados.
- Imagen: miniatura clara que represente el recurso.

## Micro‑interacciones y visuales
- AnimatedTitle: aparición por letra para titulares.
- MotionSection: transiciones de entrada suaves; viewport‑aware.
- DecorativeLayer: elementos temáticos sutiles (por módulo).
- Tokens: utiliza superficies (`card`, `muted`, `border`) y colores de marca.
